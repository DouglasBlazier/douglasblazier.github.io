      How it works

      No programming background needed. You describe the job in plain English, and Claude Code builds and runs it.

      1. 1

        Describe the job

        I explain the task the way I'd train a new hire: where the files come from, what to check and what "done" looks like.

      2. 2

        Claude builds a skill

        Claude Code writes the steps, scripts and rules into a reusable skill that reads emails, PDFs and spreadsheets and can drive desktop apps.

      3. 3

        Run it on real work

        I run the skill on that day's documents. It does the tedious part and shows me anything that needs a person's judgment.

      4. 4

        Refine and repeat

        When something's off, I say so and the skill improves. It soon becomes a one-word command I use every day.
